# Dev log — 2026-10-14 — GM☉/c² is the IAU nominal value

**Who:** R. O'Shaughnessy (with AI pair).  From Q2C PR #47's adversarial review
(finding F5); kept separate from the tidal-c_s² fix (devlog
2026-10-14-tidal-cs2) because it moves every mass.

## Defect
`constants.py` had `MSUN_SI = 1.98892e30` kg, the pre-2015 LAL value, and
computed `GMSUN_KM = G_SI * MSUN_SI / c²` with CODATA-2018 G = 6.67430e-11.  That
gives **1.4770039 km**, 2.566e-4 above the IAU 2015 Resolution B3 nominal
(GM)☉/c² = 1.4766250 km.  The comment beside it quoted 1.476625 km.

The nominal value is used by:
- LALSuite (`MRSUN_SI` = 1476.62506 m) and hence RIFT;
- the Q2C TOV oracle (`MSUN_KM = 1.476625`);
- nmbackend's own `cooling.runner` (`_GM_SUN_C2_CM = 1.4766250e5`).

The provenance of 1.98892e30 is the initial scaffold commit, with no source
note.  It is the LAL value before LAL adopted the IAU nominal GM☉.

## Fix
- `GM_SUN_SI = 1.3271244e20` m³ s⁻², exact by definition (IAU 2015 B3).
- `GMSUN_KM = GM_SUN_SI / c² / 1e3` = 1.4766250 km.
- `MSUN_SI = GM_SUN_SI / G_SI` = 1.988410e30 kg (LAL `MSUN_SI` 1.988409902e30).
  `G_SI * MSUN_SI == GM_SUN_SI`, so every derived quantity is consistent.  The
  RIFT adapter's kg → M☉ conversion uses it.
- `postmerger.GMSUN_KM = 1.4766` is a fit constant and is unchanged.
- New `tests/test_units.py::test_gmsun_km_is_iau_nominal`.  It fails on main.

## Effect
A star at given h_c is unchanged in km.  It is 2.566e-4 heavier in M☉, so every
mass ratio is exactly 1.000257 and every M-R-Λ relation in M☉ moves.  On the 18
tables of devlog 2026-10-14-tidal-cs2 (direct M = 1.4 root), on main:
- Mmax: +2.57e-4 on every table.
- Λ1.4: +1.5e-3 to +1.8e-3 (MetaModel +1.47e-3, GM1 +1.55e-3, SLy +1.71e-3);
  the family path moves by the same.
- R1.4: −0.1 to +0.6 m.
- The same shifts hold on top of the tidal-c_s² fix (to 1e-5).

Suite on SLURM: 305 passed / 94 skipped / 1 failed (main: 305 / 94 / 0), plus
the new units test.  The failure is the pin below.
