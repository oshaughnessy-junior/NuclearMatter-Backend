# Dev log — 2026-06-02 (g) — Phase 2: self-consistent RMFT EOS

**Who:** R. O'Shaughnessy (with AI pair).  Phase 2 (physics).

## Built
`eos.rmft.RMFTEOS` — a self-consistent σ-ω-ρ relativistic mean-field EOS (the
"critically physical" field-theoretic model, vs the empirical metamodel):
- Scalar Φ = g_σσ solved self-consistently via Newton on its gap equation
  (m* = M − Φ; scalar density from the relativistic Fermi gas), clamped to keep
  m* > 0; differentiable (stop-gradient + one Newton step for clean implicit diff).
- ω, ρ algebraic in the densities; β-equilibrium + charge neutrality fix the proton
  fraction (bisection + Newton; electrons, muons TODO).
- Pressure from the Gibbs relation p = μ_n n_B − ε (thermodynamically consistent),
  feeding the same h/cs² + surface-continuation pipeline as the other EOS.
- Default couplings: GM1 (Glendenning–Moszkowski 1991).

## Validation (GM1)
- **Saturation reproduced essentially exactly**: n₀=0.1530 (lit 0.153), B/A=−16.33
  (−16.3), m*/M=0.700 (0.70), K≈299 (300). This is the correctness proof.
- NS branch: M_max=2.385 M⊙ (lit ~2.36), R(1.4)=13.30 km (lit ~13.7), causal.
  The ~0.4 km R offset is the crude surface continuation (a real crust would tighten
  it) — same systematic flagged for all models.
- AD flows through the nested self-consistent solves (dM/dC_ω finite, right sign;
  ~14% vs FD at default tol — the known gradient-tolerance item, see backlog.md).
- Slots into the RIFT adapter and the reference matrix unchanged (standard EOSTable);
  GM1 added to the reference-matrix ladder.

## Bugs found & fixed (logged honestly)
- Symmetric-matter check spuriously included electrons (symmetric nuclear matter has
  none) → added a `leptons` flag; saturation then matched GM1.
- β-equilibrium residual *decreases* with x_p here (opposite of the metamodel) →
  inverted bisection gave negative proton fractions; fixed the direction.
- High-density Φ-Newton overshoot drove m* negative (nan logs) → clamp Φ < 0.98 M.
