# Free relativistic neutrino–electron/positron scattering reference

**Frozen author prototype, independent review pending.** This leaf implements actual energy-redistributing nu_a+e±→nu_a+e± scattering in a homogeneous isotropic free FD pair bath. It supplies total scattering, angular transport and signed neutrino-energy-change moments, plus an exact target-energy-shell differential redistribution kernel. It does not supply a complete neutrino inventory, medium/plasma corrections, evolving matter/radiation, or a production transport backend.

## Actual differential energy redistribution and reciprocal DOS

The local differential API returns D(E,E',c)=dΓ/(dE' dc), with units s^-1MeV^-1 per cosine and no final-nu blocking. q=k-k' is strictly spacelike for the interior angles used; q0=omega=E-E', Q=|q|, a=Q²-omega². Integrating the exact target energy delta gives

    Et,min=[-omega+Q sqrt(1+4me²/a)]/2,
    pz=[2Et omega+omega²-Q²]/(2Q),
    D=E'/(64pi³ E Q hbar) integral_Et,min^infinity dEt
          <Mavg²>_phi f(Et)[1-f(Et+omega)].

The target-spin factor2 is present; no final-neutrino DOS is inserted twice. The small negative r_perp² tolerance handles floating-point roundoff only, and a finite support failure raises. Exactly collinear/q0 coordinates require a separate limit and are rejected. Two selected points E10→E'6.3,c=-.23 and E10→E'13.7,c=.41, each for e− ande+, have independent target-energy order16→28/tail50→80 tests. Direct reversed target occupations are calculated, not synthesized by detailed balance.

For this SAME-species target, f(Et+omega)(1-fEt)/[fEt(1-f(Et+omega))]=exp(-omega/T). Combining this with the changed incident/outgoing neutrino phase prefactor gives

    D(E',E,c)/D(E,E',c)=(E/E')² exp[(E'-E)/T].

The E² ratio is essential. One-helicity DOS is rho(E)=E²/(2pi² hbarc³). Consequently rho(E)fnu(E)(1-fnu(E'))D(E,E') equals the reversed expression at any same-T neutrino FD chemical potential. This is a derived local stationarity relation, not a time integration or a forced-zero number ledger. Twelve selected differential/refinement/reciprocal tests pass.
